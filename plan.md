# Plan de mejora visual — ASTRAI Capital

## Dirección aprobada

ASTRAI adopta una estética **Midnight Institutional** inspirada en la referencia entregada: una interfaz oscura, editorial y técnica, sin incorporar el video de la referencia ni copiar su contenido.

### Principios
- **Oscuridad con profundidad:** fondos azul noche casi negros, gradientes discretos y fotografía GPU tratada con menor saturación.
- **Elegancia estructural:** bordes finos, separadores sutiles, radios pequeños y paneles con jerarquía clara.
- **Dorado de confianza:** el dorado funciona como firma de marca para CTA, cifras, líneas y estados destacados.
- **Ritmo editorial:** titulares Space Grotesk, texto DM Sans/Manrope, mucho aire y bloques de información con lectura progresiva.

### Sistema visual
- Paleta principal: `#050912`, `#080f1c`, `#0d1b31`, dorado `#c9a361` / `#f0d39a`, azul de apoyo `#6da8ed`.
- Tipografía display: Space Grotesk; cuerpo: DM Sans/Manrope.
- Bordes: 1px con blanco azulado o dorado de baja opacidad.
- Interacción: hover sobrio, elevación de tarjetas de 4px, estados de foco visibles y sin animaciones invasivas.

### Estructura
Se conserva el HTML estático y sus secciones de modelo, aplicaciones, infraestructura, economía, preguntas y contacto. La mejora se implementa en CSS para mantener el sitio simple, rápido y compatible con GitHub Pages; los recursos continúan en la raíz junto a `index.html`.
